Overview

Enter one website URL and ScrapePilot AI discovers its pages, extracts services, contact details and purpose/about information, and audits its SEO — all from real scraped data. Nothing is invented: empty sections say Not Found.

Quick start

  1. Go to Website Scraper, paste a URL, tick Scrape All Available Data and click Start Scraping.
  2. Watch the progress bar — pages are discovered from the sitemap and internal links, within your page/depth limits.
  3. Open Services, Contact and Purpose / About — they are always shown, even with zero results.
  4. Export the full report as CSV, JSON or TXT from Export Data.

AI answers need a free OpenRouter key in .env. Scraping works without one.

OpenRouter key

Copy .env.example to .env and paste a free key from openrouter.ai/keys. The key lives only on the server — never in the browser. Restart the app after adding it.

Render deployment

See README.md: pip install -r requirements.txt, start command gunicorn app:app, and set OPENROUTER_API_KEY in the Render dashboard. History is stored in SQLite on the local disk, so on Render's free tier it is lost on redeploy — use a persistent disk or an external database to keep it.
